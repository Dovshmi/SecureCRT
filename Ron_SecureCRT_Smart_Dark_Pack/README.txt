SecureCRT Smart Dark Keyword Pack
=================================

GENERAL THEMES
- NeonMax: very vivid, easiest to scan quickly.
- ArcticBlue: cool cyan/blue, good for long sessions.
- PurpleCircuit: stronger vendor/routing/L2 separation.
- AmberTerminal: warm amber/green, classic terminal feel.
- MatrixGreen: green-heavy terminal style.
- ColorblindBlueOrange: blue/orange/magenta-oriented palette.
- LowStrainSlate: muted colors for long shifts.
- HighContrast: maximum separation and brightness.

SMART PROFILES
- Troubleshooting: errors, alarms, state changes, IPs, interfaces and diagnostics are strongest.
- Routing_IPVPN: VRF, BGP/OSPF/MPLS, next-hop, route fields, neighbors and IPs are strongest.
- Layer2: VLAN/C-VLAN/S-VLAN/QinQ, MAC, interface, STP/LACP/LLDP and optical uplinks are strongest.
- Optical: SFP/DDM/Tx/Rx/dBm/CRC/FEC, MAC and physical interfaces are strongest.
- Minimal: only the operational essentials; lowest visual noise.

INSTALL
1. Copy the .ini files to the SecureCRT Config\Keywords directory.
2. Completely close and reopen SecureCRT.
3. Session Options -> Terminal -> Appearance -> Keyword Highlighting.
4. Select a profile from the List name dropdown.
5. Do NOT click New... for an imported file.

NOTE
These are keyword/highlighting profiles for use with a dark terminal background.
They do not change SecureCRT's background color or font by themselves.
